# IQPI Sudoku Camera — Android 6×6

**Проект Android-приложения для POCO X5 Pro 5G и других Android-телефонов (Android 8.0 и новее).**

Приложение показывает видеопоток с **задней камеры**. Телефон направлен на монитор с игрой IQPI. Каждые 0,65 секунды программа выделяет центральный квадрат игрового поля, распознаёт крупные белые цифры `1…6`, решает классическое судоку **6×6** с блоками **2×3** и поверх видео выделяет клетку первой подсказки. Под камерой показывается распознанное поле: **белые** — исходные цифры, **бирюзовые** — найденное решение. Не нужны интернет, сервер, аккаунт или вход в IQPI.

## Что умеет

- Живое распознавание цифр из камеры телефона, без отдельной кнопки «Сделать фото».
- Выравнивающая сетка 6×6 на экране камеры, ручное увеличение камеры.
- Два одинаковых последовательных кадра для подтверждения результата; неуверенные цифры требуют исправления.
- Решатель проверяет правильность и *единственность* решения, прежде чем показать ответы.
- Крупная подсказка «Строка N · столбец M → цифра» и целиком заполненная сетка решений.
- Кнопка «Пауза / правка» для исправления ошибочных распознаваний.
- Отдельный режим Killer: ручной ввод всех клеток групп и сумм, затем решение с учётом сумм. **Автораспознавания пунктирных клеточных групп и их сумм пока нет**.
- Включён тестовый пример из скриншота (кнопка «Проверить на примере со скриншота»).

**Важно:** подсказки могут нарушать правила турнира. Перед использованием в соревновании проверьте условия IQPI. Приложение не управляет сайтом и не скрывает своё присутствие: оно только показывает подсказки владельцу телефона.

## Готовый APK и автоматическая проверка

Откройте **Actions → Build IQPI Sudoku APK → последний успешный запуск**. В разделе **Artifacts** скачайте **IQPI-Sudoku-POCO-X5-Pro-APK**, распакуйте ZIP и установите `app-debug.apk` на телефон. Это подписанная отладочная сборка для проверки приложения. Рядом находится SHA-256 файла.

Workflow выполняет `testDebugUnitTest`, `lintDebug` и `assembleDebug`. APK публикуется в артефактах только после успешной проверки. Результаты тестов доступны в сводке запуска, полные отчёты — в `verification-reports`.

Сборка использует JDK 17, Gradle 8.9, Android Gradle Plugin 8.7.3, Kotlin 2.0.21, Android SDK 35 и CameraX 1.4.2. Android command-line tools устанавливаются перед вызовом `sdkmanager`. Gradle Wrapper создаётся стандартной задачей `gradle wrapper`.

Каждый push в `main` запускает проверку; также доступна кнопка **Run workflow**. Поддерживается проверка pull request. Публикация GitHub Release не настроена.

## Сборка на Windows

1. Установите Android Studio и Android SDK Platform 35. Используйте JDK 17.
2. Скачайте исходники, распакуйте и запустите `prepare-wrapper.bat`: он получает официальный Gradle Wrapper 8.9 и проверяет его контрольную сумму.
3. Откройте в Android Studio папку с `settings.gradle.kts` и дождитесь Gradle Sync.
4. В терминале проекта выполните `gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`.
5. Установочный файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

На POCO X5 Pro 5G откройте APK, разрешите установку из выбранного источника и предоставьте приложению доступ к камере. Минимальная версия системы — Android 8.0 (API 26).

## Как пользоваться

1. Откройте IQPI на экране компьютера (или второго устройства) и запустите судоку 6×6.
2. Держите POCO **вертикально** перед экраном. Поверните и приблизьте телефон так, чтобы **граница 6×6** точно совпала с нарисованной зелёной сеткой; по возможности уберите блики и муар. При необходимости измените увеличение.
3. Дождитесь текста об успешном распознавании. **Бирюзовые цифры** в нижней сетке — все ответы; верхняя крупная надпись — первая рекомендуемая клетка.
4. Если какая-либо цифра определена неверно, нажмите «Пауза / правка», коснитесь соответствующей клетки нижней сетки и введите правильное значение. Нажмите «Продолжить сканирование», когда понадобится обновить цифры с экрана.
5. Для Killer выберите «Режим: Killer». Если у поля есть пунктирные группы с суммами, в режиме паузы добавьте каждую группу: выберите её клетки на нижней сетке и укажите сумму. Повторите для всех 36 клеток. Только после этого появляются ответы для Killer.

## Ограничения

- **Видео** берётся из `PreviewView` камеры, но распознаётся центральный квадрат, очерченный сеткой. Это не потоковый захват экрана Chrome и не видеопоток сайта IQPI.
- Распознавание настроено на белые цифры IQPI с предоставленного скриншота и ровно выставленное поле; при заметном перспективном искажении, другом шрифте, изменённой теме или бликах нужно ручное исправление. Автоматического выпрямления перспективы пока нет.
- Реальные условия съёмки камерой **POCO X5 Pro 5G**, автофокус, увеличение и установка на физическое устройство автоматически не проверялись. Robolectric проверяет Android-код в тестовой среде, а не на телефоне.
- Первый запуск и сборка проекта требуют интернет для Android Studio и Gradle. **Само мобильное приложение интернет-доступ не запрашивает**.
- Не ищет ходы или оппонента в памяти/коде IQPI, не вводит числа на другом устройстве.

## Структура проекта

- `app/src/main/java/io/iqpi/sudokuhelper/MainActivity.kt` — интерфейс, камера CameraX и обновление подсказок.
- `app/src/main/java/io/iqpi/sudokuhelper/DigitRecognizer.kt` — локальное распознавание цифр.
- `app/src/main/java/io/iqpi/sudokuhelper/SudokuSolver.kt` — решатель классики и Killer.
- `app/src/main/java/io/iqpi/sudokuhelper/GridViews.kt` — две сетки: поверх камеры и с полным решением.
- `app/src/main/assets/digits/` — локальные эталоны цифр.
- `app/src/test/` и `verification/` — тестовые файлы и эталонное поле.

## Автоматические тесты

- **13 тестов решателя:** сетка 6×6 и блоки 2×3, единственность, противоречия, неверный ввод, независимость Classic от сохранённых Killer-групп, смешанные размеры групп, суммы, отсутствие повторов и полное покрытие поля.
- **4 теста распознавания на Android Bitmap (Robolectric):** эталонный скриншот при размерах 730, 540, 400, 320 и 270 пикселей; все шесть цифр; пустые клетки и маленькие суммы; неизвестная яркая фигура.
- **4 теста интерфейса:** запуск без доступа к камере и демонстрационный пример, переключение Classic/Killer, сброс состояния демонстрацией, блокировка решения до исправления всех неуверенных цифр.

На эталонном скриншоте значения всех 36 клеток распознаются верно. При уменьшении до 270×270 две цифры требуют ручного подтверждения: это предусмотренное консервативное поведение, порог уверенности не снижен. При 320×320 и выше этот пример не требует правки. Эти результаты не гарантируют такую же точность при съёмке физического экрана.
