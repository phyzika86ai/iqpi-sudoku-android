# IQPI Sudoku Camera — Android 6×6

**Проект Android-приложения для POCO X5 Pro 5G и других Android-телефонов (Android 8.0 и новее).**

Приложение показывает видеопоток с **задней камеры**. Телефон направлен на монитор с игрой IQPI. Примерно два раза в секунду программа выделяет игровое поле, распознаёт крупные белые цифры `1…6`, решает классическое судоку **6×6** с блоками **2×3** и поверх видео выделяет клетку первой подсказки. Под камерой показывается распознанное поле: **белые** — исходные цифры, **бирюзовые** — найденное решение. Не нужны интернет, сервер, аккаунт или вход в IQPI.

## Что умеет

- Живое распознавание цифр из камеры телефона, без отдельной кнопки «Сделать фото».
- Выравнивающая сетка 6×6 на экране камеры, ручное увеличение камеры.
- Два одинаковых последовательных кадра для подтверждения результата; неуверенные цифры требуют исправления.
- Решатель проверяет правильность и *единственность* решения, прежде чем показать ответы.
- Крупная подсказка «Строка N · столбец M → цифра» и целиком заполненная сетка решений.
- Кнопка «Пауза / правка» для исправления ошибочных распознаваний.
- Отдельный режим Killer: ручной ввод всех клеток групп и сумм, затем решение с учётом сумм. **Автораспознавания пунктирных клеточных групп и их сумм пока нет**.
- Включён тестовый пример из скриншота (кнопка «Проверить на примере со скриншота»).

**Важно:** подсказки могут нарушать правила турнира. Перед использованием в соревновании проверьте условия IQPI. Приложение не управляет сайтом и не скрывает своё присутствие: оно только показывает подсказки владельцу телефона.

## Сборка APK в GitHub Actions (без Android Studio)

В проект включён файл `.github/workflows/build-apk.yml` для автоматической сборки **установочного debug APK** на GitHub. Для этого потребуется аккаунт GitHub и интернет:

1. Создайте новый репозиторий GitHub (можно приватный) и загрузите **содержимое** папки проекта, включая скрытую `.github`. Для правильной работы важно сохранить именно `.github/workflows/build-apk.yml`.
2. Откройте в репозитории вкладку **Actions → Build IQPI Sudoku APK**. При необходимости включите Actions и нажмите **Run workflow** (или сборка стартует после `push` в ветку `main`).
3. После успешного завершения откройте запуск → **Artifacts → IQPI-Sudoku-POCO-X5-Pro-APK**. Скачайте ZIP-артефакт, распакуйте `app-debug.apk`.
4. Перенесите `app-debug.apk` на POCO X5 Pro 5G и откройте, разрешив установку из выбранного источника и доступ к камере.

**Важно:** этот workflow подготовлен, но пока **не запускался в GitHub Actions**, а APK в текущем окружении не собран. Если сборка завершится ошибкой, откройте лог шага `Compile installable debug APK`.

## Как получить APK для POCO X5 Pro 5G (Windows)

Этот архив — **исходный проект Android Studio**, а **не готовый установочный APK**. В рабочем окружении Android SDK и сборщика APK нет, поэтому сборка на реальном телефоне пока не проверялась.

1. На компьютере с Windows установите **Android Studio** с сайта https://developer.android.com/studio . При первом запуске установите предложенные Android SDK и инструменты. Для проекта необходим Android SDK Platform **35** и JDK **17** (подойдёт встроенный JDK Android Studio).
2. Распакуйте ZIP. Запустите `prepare-wrapper.bat` — скрипт скачает официальный маленький загрузчик **Gradle 8.9** и проверит контрольную сумму с сайта Gradle. Для этого нужен интернет. Если загрузка не удалась, проверьте доступ к `https://services.gradle.org/distributions/`.
3. В Android Studio выберите **Open** и укажите **папку `IQPI_Sudoku_Android`**, содержащую файл `settings.gradle.kts` (не файл и не папку `app`). Подтвердите открытие проекта.
4. Дождитесь **Gradle Sync**: IDE автоматически докачает нужные библиотеки CameraX, Kotlin, Android Gradle Plugin.
5. Выберите меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**. После успешной сборки файл будет по пути `app/build/outputs/apk/debug/app-debug.apk` внутри проекта.
6. Передайте APK на POCO X5 Pro 5G и откройте на телефоне. Разрешите установку из этого источника, затем дайте приложению доступ к камере.

**Вариант без ручной передачи APK:** включите «Для разработчиков» на POCO (несколько нажатий по версии MIUI/HyperOS в «О телефоне»), включите «Отладка по USB», подключите телефон к компьютеру, выберите его в Android Studio и нажмите ▶ **Run**.

## Как пользоваться

1. Откройте IQPI на экране компьютера (или второго устройства) и запустите судоку 6×6.
2. Держите POCO **вертикально** перед экраном. Поверните и приблизьте телефон так, чтобы **граница 6×6** точно совпала с нарисованной зелёной сеткой; по возможности уберите блики и муар. При необходимости измените увеличение.
3. Дождитесь текста об успешном распознавании. **Бирюзовые цифры** в нижней сетке — все ответы; верхняя крупная надпись — первая рекомендуемая клетка.
4. Если какая-либо цифра определена неверно, нажмите «Пауза / правка», коснитесь соответствующей клетки нижней сетки и введите правильное значение. Нажмите «Продолжить сканирование», когда понадобится обновить цифры с экрана.
5. Для Killer выберите «Режим: Killer». Если у поля есть пунктирные группы с суммами, в режиме паузы добавьте каждую группу: выберите её клетки на нижней сетке и укажите сумму. Повторите для всех 36 клеток. Только после этого появляются ответы для Killer.

## Ограничения

- **Видео** берётся из `PreviewView` камеры, но распознаётся центральный квадрат, очерченный сеткой. Это не потоковый захват экрана Chrome и не видеопоток сайта IQPI.
- Распознавание настроено на белые цифры IQPI с предоставленного скриншота и ровно выставленное поле; при заметном перспективном искажении, другом шрифте, изменённой теме или бликах нужно ручное исправление. Автоматического выпрямления перспективы пока нет.
- Сетка и цифры из скриншота проверены в локальном тесте, но реальные условия съёмки камерой **POCO X5 Pro 5G** и Android-сборка **не проверены**.
- Первый запуск и сборка проекта требуют интернет для Android Studio и Gradle. **Само мобильное приложение интернет-доступ не запрашивает**.
- Не ищет ходы или оппонента в памяти/коде IQPI, не вводит числа на другом устройстве.

## Структура проекта

- `app/src/main/java/io/iqpi/sudokuhelper/MainActivity.kt` — интерфейс, камера CameraX и обновление подсказок.
- `app/src/main/java/io/iqpi/sudokuhelper/DigitRecognizer.kt` — локальное распознавание цифр.
- `app/src/main/java/io/iqpi/sudokuhelper/SudokuSolver.kt` — решатель классики и Killer.
- `app/src/main/java/io/iqpi/sudokuhelper/GridViews.kt` — две сетки: поверх камеры и с полным решением.
- `app/src/main/assets/digits/` — локальные эталоны цифр.
- `app/src/test/` и `verification/` — тестовые файлы и эталонное поле.

## Результаты локальных тестов

- 36/36 клеток верно на *обрезанном скриншоте* и его уменьшенных копиях до 270×270.
- Единственное решение тестовой 6×6 сетки найдено; конфликтующие цифры отвергнуты.
- Killer проверен на тестовом разбиении на одноэлементные группы.

Это не гарантирует 36/36 при съёмке физического экрана телефоном.
